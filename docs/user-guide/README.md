# Densemble user guide

This guide is for people who **use** Densemble: how to set up a
feature, what to do every day, and what to do when something goes wrong. Developer
details (architecture, file contracts, tests) live in [native setup](../native-setup.md)
and [contracts](../contracts.md). Installation: [INSTALL.md](../../INSTALL.md).

For the big picture first, read [what Densemble does](../overview.md) and
[how it is built](../concepts.md).

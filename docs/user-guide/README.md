# Densemble user guide

This guide is for people who **use** Densemble on their own Mac: how to set up a
feature, what to do every day, and what to do when something goes wrong. Developer
details (architecture, file contracts, tests) live in the [developer guide](../development.md)
and [contracts](../contracts.md).

## Chapters

- [Recording transcription](recordings.md): turn recorded calls, lectures and
  meetings into text automatically.

Installation: [INSTALL.md](../../INSTALL.md). Telegram bots, voice messages, background
operation and backups are described in the [developer guide](../development.md).

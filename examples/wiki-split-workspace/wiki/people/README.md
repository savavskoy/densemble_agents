# People

One profile per person who talks to the agents here, the owner included: `<first-name>.md` in
this folder (lowercase Latin letters, e.g. `alex.md`). Glim creates it on the first conversation
with that person and fills it in from the template below. Agents read the profile of the person
they are talking to at the start of every conversation, and never write one person's details into
another person's profile.

```markdown
# <Name>

- **Role:** owner / member
- **How to address me:**
- **Language:**
- **What I mostly want help with:**
- **Atmosphere:** story / plain
- **Handover:** not done
- **Declined agent suggestions:**
```
